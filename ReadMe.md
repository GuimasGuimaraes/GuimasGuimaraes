## About me

I'm a **Systems Analyst working in application support and production incident investigation**. My day-to-day experience involves troubleshooting applications and integrations, analyzing logs and API requests/responses, working with Oracle databases, and collaborating on root-cause analysis and fixes.

I'm now building on that background to transition into **Application Security (AppSec)**, with a particular interest in **web applications, API security, access control, and secure development**.

I approach security from a practical perspective: understand how a system works, reproduce the behavior, collect evidence, and explain the risk clearly.
